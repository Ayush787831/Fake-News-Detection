Machine Learning Architecture

1

Data Ingestion & Cleaning

LIAR benchmark dataset (10,240 training statements). Tokenization, lowercase transformation, stopword removal, and punctuation handling.

2

Feature Extraction & n-grams

TF-IDF Vectorization with unigrams, bigrams, trigrams, and 4-grams (1-4 ngram range), sublinear term frequency scaling, and IDF smoothing.

3

Classification & Probability Calibration

L2 Regularized Logistic Regression (C=1.5) calibrated with softmax probabilities for continuous veracity scoring.

REST API Documentation

POST /api/predict

Integrate TruthLens fake news detection directly into any application or workflow via JSON HTTP POST.

Request Payload:

POST /api/predict
Content-Type: application/json

{
  "news": "The economic turnaround started at the end of my term."
}

Response Payload:

{
  "success": true,
  "statement": "The economic turnaround started at the end of my term.",
  "prediction": "REAL NEWS",
  "label": "TRUE",
  "is_real": true,
  "truth_probability": 64.58,
  "fake_probability": 35.42,
  "confidence_score": 64.6,
  "explanations": [
    {"word": "end term", "weight": 0.53, "direction": "real"},
    {"word": "economic", "weight": 0.392, "direction": "real"}
  ],
  "metrics": {
    "word_count": 9,
    "character_count": 55,
    "reading_time_sec": 3
  },
  "timestamp": "2026-09-26 23:30:00"
}

Quick cURL Example:

curl -X POST http://127.0.0.1:5000/api/predict \
  -H "Content-Type: application/json" \
  -d '{"news": "Health care reform legislation mandates free surgeries."}'
